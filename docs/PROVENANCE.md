# Provenance

This experiment was authored by an LLM at the project owner's request, using
TypeScript-generated SVG geometry rather than a raster image-generation model.
The player, sentinel, projectile, effects, poses, and export tooling are newly
written for this pipeline.

Visual reference: the sibling Feedback project's recovered Figma Make artwork in
`feedback/psw/pitch_slides/assets/figma-characters/` (`player-idle.svg`, `enemy.svg`,
and `CharacterShowcase.tsx`), inspected on 2026-11-03. Muted armor, moss colors,
blocky construction, and violet parry cues inform the direction. This is a new rig,
not a claim to reproduce the original animation. The original recovered files and
their provenance remain in the sibling repository and are not modified here.

No third-party asset packs, image-generation API outputs, or downloaded textures
are included. This record describes origins; it does not assert ownership of the
Figma references or grant a license to them. A public distribution license for this
new repository has not been selected by the project owner.
